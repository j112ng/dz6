### Условие задачи
Дано шестизначное число. Определить, является ли оно «счастливым».
(Счастливым считается число, у которого сумма первых трех цифр равна сумме последних трех цифр).

### 1. Алгоритм и блок-схема

**Алгоритм:**
1. Начало.
2. Объявить переменные: `n`, `sum1`, `sum2`, `temp`.
3. Ввести шестизначное число `n`.
4. Проверить, что число шестизначное (от 100000 до 999999). Если нет — вывести ошибку и завершить.
5. Скопировать значение `n` в переменную `temp` для дальнейшей работы с цифрами.
6. Вычислить сумму последних трех цифр (`sum2`).
7. Вычислить сумму первых трех цифр (`sum1`).
8. Сравнить `sum1` и `sum2`.
9. Вывести результат («счастливое» или «не счастливое»).
10. Конец.

### 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
#include <stdlib.h>

int main() {
    system("chcp 65001 > nul"); 
    setlocale(LC_ALL, "RUS");

    int n;
    int sum1 = 0;
    int sum2 = 0;
    int temp;

    printf("Введите шестизначное число: ");
    scanf("%d", &n);

    if (n < 100000 || n > 999999) {
        printf("Ошибка: число должно быть шестизначным!\n");
    } else {
        temp = n;

        sum2 += temp % 10;
        temp /= 10;
        sum2 += temp % 10;
        temp /= 10;
        sum2 += temp % 10;
        temp /= 10;

        sum1 += temp % 10;
        temp /= 10;
        sum1 += temp % 10;
        temp /= 10;
        sum1 += temp % 10;

        if (sum1 == sum2) {
            printf("Число %d является счастливым!\n", n);
        } else {
            printf("Число %d не является счастливым.\n", n);
        }
    }

    return 0;
}
```
